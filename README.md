# My Portfolio

A stunning, modern personal portfolio website built with React, Vite, and pure CSS.

## Features
- Responsive design
- Smooth animations
- Contact form with EmailJS
- Project showcase
- Skills section
  
## Tech Stack
- React 19
- Vite 8
- Bootstrap 5
- CSS3
- EmailJS

## Getting Started
```bash
git clone https://github.com/therealphearunpo/My-portfolio.git
cd My-portfolio
npm install
npm run dev
```
